# Wonder Duck 的 48 个仿真任务

想先看鸭子动起来，可以打开[仿真短片](../runs/showcase/wonder-duck.mp4)。想看每项怎么判分，可以打开[实验记录](simulation-results.md)。下表的“实测”只指这次使用幻尔公开机器人模型的本地 MuJoCo 实验。P0 优先解决能解锁后续任务的问题，P1 用来组合已验证的能力，P2 是综合挑战。数值写在待办栏时代表验收目标。

## 实施顺序

先做 20–22 和 35。可用第 19 项的控制器研究桌缘附近的推送，并记录灯光、物体大小变化时的视觉误差。随后做 26、32、38、43，把单项技能组合成分拣、提环、交通灯和选角射门。结合实物前，向幻尔核对当前 SKU 的鸭嘴结构、相机标定、舵机映射及部署接口。机器人上的 PPO 训练和导出需要匹配的可编辑工程。资源出处见[官方资料清单](official-assets.md)。

夜间执行器轮换前 18 个已实现任务并记录新种子。每晚的开发任务从后续条目选一项，在独立数据上与基线对照后更新本表。运行、停机和查看视频的方法见[夜间队列](simulation-results.md#夜间队列)。
