任务事件试播

以下按钮仅触发声音，不运行机器人动作。资源键与任务 SDK 共用。

同一实例的同一事件只播放一次；修改实例 ID 可测试下一次任务。

接入你的任务模块

from duckaudio import AudioClient
from duckaudio.tasks import TaskAudio

client = AudioClient("unix:/run/wonderduck-audio/audio.sock")
audio = TaskAudio(client, task_id="retrieval-001")
audio.emit("started")
audio.emit("target_found")
audio.emit("succeeded")
# 用户取消任务时：audio.cancel()

事件提交在后台发送，音频错误可从 Future 和任务日志读取。批量仿真使用 LogAudioClient。
